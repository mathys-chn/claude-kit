# kit-band (mod de claude-kit)

Bande affichée au-dessus du prompt de Claude Code (app de bureau, VS Code, terminal) : limites 5 heures, semaine et budget mensuel avec rythme, projection et heure de remise à zéro ; remplissage du contexte avec bouton /compact ; coût, coût par heure et durée ; branche git, fichiers modifiés et âge du dernier commit ; durée du dernier tour.

Tapez `/kit` (ou cliquez sur ⚙) pour ouvrir le panneau de réglages : ordre et affichage des éléments, style des puces, couleurs, nom affiché, notifications et sons, garde-fous de sécurité, formatage automatique et statusline du terminal. Tout est enregistré dans `~/.claude/claude-kit/config.json`, le même fichier que lisent les hooks de claude-kit.
