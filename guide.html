claude-kit

Une statusline qui te dit tout, des garde-fous contre les commandes destructrices, des notifications quand Claude a fini, et 11 commandes en français. Zéro dépendance, Node 18+ suffit.

git clone https://github.com/mathys-chn/claude-kit.git && cd claude-kit && node install.js
macOS · Linux · Windows/WSL Sauvegarde auto de ta config Relançable sans doublon --uninstall pour tout retirer
Statusline

Deux lignes, tout l'essentiel

Dans le terminal, c'est la statusline. Dans l'app de bureau et VS Code, les mêmes infos s'affichent en pastilles au-dessus du prompt (bande kit-band), avec un bouton /compact quand le contexte dépasse 80 %, le budget mensuel et la durée du dernier tour. Survole un élément de la légende pour le repérer.

Hook guard

Les garde-fous

Avant chaque commande ou accès fichier, guard décide. Tout est noté dans ~/.claude/claude-kit/security.log.

Bloqué jamais exécuté

  • rm -rf /, rm -rf ~, --no-preserve-root
  • curl … | sh (script distant)
  • git push --force sur main / master / prod
  • mkfs, dd of=/dev/…, fork bomb
  • DROP DATABASE, chmod 777 /, shutdown

Confirmation Claude te demande

  • sudo, rm -r, kill -9
  • git reset --hard, clean -f, branch -D
  • DELETE sans WHERE, DROP TABLE, reset de BDD
  • npm publish
  • Fichiers .env, clés SSH, .pem, credentials

Automatique les autres hooks

  • format : Biome, Prettier, Ruff, gofmt ou rustfmt après chaque modif
  • notify : notif système quand une tâche de plus de 20 s se termine ou attend ton accord
  • session-start : Claude démarre en connaissant ta branche et tes derniers commits

Réglages

Tout se règle avec /kit

Un panneau s'ouvre dans Claude. Chaque changement s'applique tout de suite et s'enregistre dans ~/.claude/claude-kit/config.json, le fichier que lisent aussi les hooks et la statusline.

OngletCe qu'on y règle
BandeUne ou deux lignes, style des puces (arrondi, carré, contour, texte), ordre et affichage de chaque élément, rythme et heure de reset
Couleurs9 thèmes ou ta couleur en hex, nom affiché, devise, budget par session
NotificationsFin de tâche, demande d'accord, durée minimale, son et choix du son, heures calmes
SécuritéBlocage des commandes destructrices, confirmation des commandes risquées, protection des secrets, journal
AutomatisationsFormatage par langage, résumé du dépôt en début de session, icônes de la statusline
À proposChemin du fichier de réglages, réinitialisation
 
# Ouvrir directement un onglet
/kit notifications
/kit sécurité

# Couper un hook pour une session, sans toucher aux réglages
CLAUDE_KIT_NOTIFY=0 claude
CLAUDE_KIT_FORMAT=0 claude
